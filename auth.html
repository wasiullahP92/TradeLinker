Production Backend Integration Guide

SRS Tech Stack: Supabase / Firebase

TradeLinker is architected with dual-backend support:

  1. Current Active Mode: Client-side Cryptographic Sandbox Vault (PBKDF2/SHA-256 salted hashes, zero plain text, isolated sessions).
  2. Production Cloud Backend: Fully compatible with Supabase PostgreSQL Auth.
    1. Open Supabase Dashboard & execute supabase-schema.sql in SQL Editor.
    2. Insert your project URL & Anon Key into js/config.js.
    3. Set authProvider: "supabase".
